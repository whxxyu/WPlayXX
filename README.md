# WPlayXX

> Addon all-in-one untuk Nuvio: katalog, stream, dan subtitle dalam satu pemasangan.

WPlayXX adalah addon premium all-in-one untuk [Nuvio](https://nuvio.tv) yang menyediakan 58 katalog film, serial, dan anime, lengkap dengan stream dan subtitle Bahasa Indonesia — tanpa addon pendamping.

---

## Instalasi

1. Buka Nuvio, pilih menu **Addons**, lalu **Install via URL**.
2. Masukkan URL manifest berikut:

```
https://wplayxx.whxxyu.biz.id/manifest.json
```

3. Konfirmasi pemasangan. Katalog akan tampil di beranda dan menu Discover.

Tidak memerlukan akun maupun pengaturan tambahan.

---

## Fitur

- **58 katalog** film, serial, dan anime dalam satu addon.
- **Stream terintegrasi** untuk film, serial, dan anime, dengan rincian kualitas lengkap: resolusi hingga 4K, format, codec, HDR, dan ukuran file.
- **Subtitle Bahasa Indonesia** yang menyatu dengan pemutar dan mengikuti rilis yang diputar.
- **Satu pemasangan** — katalog, stream, dan subtitle aktif sekaligus, tanpa addon tambahan.
